# Приложение для отбора вин

Приложение оценивает вероятность того, что вино получит оценку не ниже 7.

## Локальный запуск

Использовался Python 3.12.7.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r wine_app/requirements.txt
streamlit run wine_app/app.py
```

Команды запускаются из корня репозитория.

## Кэширование

`st.cache_resource` хранит одну загруженную модель, чтобы не читать файл заново после каждого действия
 `st.cache_data` хранит таблицу и готовые вероятности для тестовых вин. когда я двигаю порог, приложение просто сравнивает эти вероятности с новым числом

без кэша `joblib.load` загружал бы модель при каждом движении ползунка, и приложение работало бы медленнее.
