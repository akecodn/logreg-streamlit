# logreg-streamlit

В ноутбуке `HW3_MMDA.ipynb` выполнены задания 1–3. 

В папке `wine_app` находится приложение для части 4.

## Запуск приложения

Версия Python: 3.12.7. Выполните из корня репозитория:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r wine_app/requirements.txt
streamlit run wine_app/app.py
```
